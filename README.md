# メール・文書安全チェッカー用フィッシング規則

このリポジトリは、ローカル実行型ツール **「メール・文書安全チェッカー」** が参照する公開フィッシング規則ファイルを配布するためのものです。

## 目的

この規則ファイルは、メール本文・文書・添付ファイル名などに含まれる不審な特徴を検出し、利用者に注意喚起するために使用します。

主な検出対象は以下です。

* 社長・役員・上司を装った指示
* LINEグループ作成やQRコード返信の要求
* 振込・口座残高確認・口座変更の依頼
* パスワード・認証コード・APIキー等の要求
* 緊急性や秘密保持を強調する表現
* 実行形式ファイルや二重拡張子の添付ファイル名
* QRコードや短縮URLを使った誘導
* フリーメールや未確認ドメインからの不自然な業務依頼

## 重要な運用方針

このリポジトリは公開リポジトリです。
そのため、以下の情報は絶対に登録しません。

* 会社名
* 取引先名
* 顧客名
* 実際のメール本文
* 契約書・見積書・稟議書などの本文
* 会社の公式メールドメイン一覧
* 社内ルール
* 検査結果
* 個人情報
* 機密情報

ここに登録するのは、公開情報をもとにした一般的なフィッシング判定規則のみです。

## 規則ファイル

アプリが読み込むファイルは以下です。

```text
phishing-rules.json
```

アプリの「最新情報を更新」ボタンを押すと、このJSONファイルを取得して、ローカル環境の判定規則を更新します。

メール本文・文書内容・検査結果は、このリポジトリには送信されません。

## 更新方針

原則として、2週間に1回程度、上記の公開情報を確認し、必要に応じて `phishing-rules.json` を更新します。

ただし、企業を狙った新しい手口や、社長・役員なりすまし、QRコード悪用、送金指示、認証情報要求などの重大な手口が確認された場合は、定期更新を待たずに更新します。

## 更新時の確認項目

更新時には、以下を確認します。

* 新しいフィッシング手口が公開されていないか
* 業務メールで使われやすい自然な文面に偽装していないか
* QRコード、LINE、SMS、SNS、クラウドサービスを悪用した誘導が増えていないか
* 添付ファイル名や拡張子を偽装する手口が増えていないか
* 「至急」「本日中」「秘密」「電話できない」などの確認回避表現が使われていないか
* 現在の規則で過剰検知・見逃しが起きやすくなっていないか

## 免責

この規則ファイルは、フィッシングや情報漏えいのリスクを減らすための補助的なものです。

すべての不審メールを検出できることを保証するものではありません。
また、「問題なし」と表示された場合でも、メールの安全性を完全に保証するものではありません。

不審な点がある場合は、メールに返信せず、社内電話・対面・公式連絡先など、別の手段で確認してください。
